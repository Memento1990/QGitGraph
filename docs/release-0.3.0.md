## 当前实现与使用边界

- 正式前端使用 **Vue 3、Reka UI、本地可编辑 shadcn-vue 组件**，通过类型化 Tauri 2 IPC 调用 Rust Host；旧原生 DOM 界面和浏览器原型不代表当前正式入口。没有通用 shell / HTTP bridge，产品不依赖本机任务看板服务。
- 左侧为**目录、子模块、标签、储藏四个同级根**；后三组跟随当前仓库。仓库行保留分支切换入口和同行快捷操作，不增加分支侧树。目录发现是有界纯文件系统扫描，候选摘要另走有界只读请求，不自动 fetch。
- 历史、详情、父提交选择、文件列表、统一/双栏 Diff 和审阅迁移到 Vue。**新 profile 默认右侧详情**，已有显式布局偏好（包括 inline）保留，不强制覆盖。语言和完整偏好通过设置调整，不把旧版底部快捷入口写成当前能力。
- 本地修改分为已暂存、未暂存、未跟踪。暂存/取消暂存针对明确文件或确认分组；提交绑定 HEAD 与索引快照，仅提交已有索引内容，不自动 add。同步按明确上游先 pull，冲突、失败或取消后不继续 push。
- 目录授权、单仓允许/拒绝/继承由 Rust 的独立 `native-trust.json` 保存，绑定规范身份与原生授权 epoch；撤销使旧请求失效，renderer state 和共享配置不能授予信任。选择目录不等于授权其下全部仓库。
- 可选 runtime usage 默认关闭，显式开始后仅写当前 profile 的本机有界日志。记录白名单标识/计数/状态，关联 `appVersion`、`sourceBuild` / `sourceBuildReliable` 与运行时计算的 `exeSha256`；不记录代码、Diff 正文、提交说明、自由输入、凭据或真实私有路径，不联网上传。
- 检查更新仍为设置中的手动操作，由 Rust 请求固定 GitHub latest endpoint；只打开经校验的官方发布页，不自动下载/安装。renderer CSP 不开放任意 HTTP。

本轮界面范围是**宽屏深色与浅色**，不据此推断窄屏、Windows 10、多屏 DPI 或读屏器验收。更多安全与分发限制见 [安全模型](../SECURITY.md)。

# QGitGraph 0.3.0 — 目录导航、语言与状态信息

本轮为本地交付，不创建 GitHub tag、提交或新的公开 Release。公开下载链接始终指向 GitHub 实际的最新稳定版，不把本地新版本说成已经发布。

## 界面与使用

### 打开单仓库或仓库目录

- 继续使用“打开仓库”或“通过路径打开”直接进入工作树、仓库子目录或 bare 仓库。
- “打开目录”选择包含多个项目的目录，左侧显示该扫描范围内的仓库和祖先目录，不展示普通源文件。
- “通过路径打开目录”可输入路径与 0–5 层搜索深度；新目录默认 2 层。深度指相对所选根的子目录层数，不代表扫描整块磁盘。
- 仅当前激活仓库运行历史、工作区、Diff 和 watcher。未激活仓库不批量查询分支或脏状态，不虚构实时信息。
- 目录树方向键移动/展开，Enter 激活仓库；点击展开箭头不切换仓库。支持根本身也是仓库和其下嵌套仓库同时出现。
- 完整扫描仅一个仓库，成功打开后自动收起左栏；工具栏开关始终可以恢复。手动偏好不应被刷新/重启覆盖。截断或有警告的扫描不宣称只有一个仓库。
- “关闭仓库”保留目录导航，“关闭目录”另行清除导航范围；均不删除磁盘内容或审阅/信任记录，也不终止用户外部终端。
- 仓库视图沿用原有 repository ID 隔离：筛选、选择、滚动、Diff、review 与设置不跨仓库串用。

目录扫描仅检查文件系统标记，不启动 Git、不克隆、不信任所有候选，不把所有候选加入最近列表。候选在激活时重新验证。`.git` 文件对应的管理目录可以合法在范围外，但扫描不会跟随它继续遍历。

### 中英文

设置顶部的全局语言选项：**跟随系统 / 简体中文 / English**。底部语言入口亦可快捷切换。

- 首次跟随系统；支持的中文界面为简体中文，其他不支持语言回退 English。
- 显式选择持久化，不随仓库切换或共享配置导入改变。
- 切换只更新应用自有文本/属性和日期数字格式，不重新打开仓库、重新查询历史/Diff 或触发检查更新。
- 保留现有输入、设置草稿、焦点/光标、提交/文件选择、滚动、对比和审阅；原始提交消息、作者、路径、分支/tag、代码、Git/终端输出及发布说明不翻译。
- 原生窗口系统按钮仍遵循 Windows 设置；应用提供的文件选择器标题使用应用语言。

### 底部状态栏

约 28px、中性背景、三段布局：

1. **上下文**：仓库、可识别的 WSL 存储位置、分支 / detached / unborn，以及只读/信任。
2. **工作区**：干净/修改/冲突/获取中/未知/旧数据待刷新，非零/展开后的暂存、未暂存、未跟踪与冲突数，merge/rebase 等进行中状态。
3. **活动**：当前查询显示/已加载数量、正在执行的任务、准确取消范围、最后成功工作区刷新、结果/错误与语言入口。

完整路径、上游说明、分类计数、刷新时间和诊断通过可键盘访问的状态详情查看，窄窗口不会挤出多行状态条。上游 ahead/behind 来自当前本地 porcelain 数据，不自动 fetch；没有准确计数就不显示假的同步零值。

分类计数按不同路径统计：冲突/未跟踪单列，已暂存与已跟踪未暂存可能重叠，不能简单相加。bare 仓库显示无工作区而不是干净；加载失败后的旧快照不冒充新鲜状态。

## Windows 环境块修复

`Invalid Git environment variable name.` 来自 Git 启动前的原生环境块验证，不足以证明是 WSL 路径错误。

旧实现已支持盘符隐藏变量，但把继承条目与显式变量混用同一验证器。独立子进程对照复现：仅盘符条目通过，加入非盘符的单前导 `=` 继承条目后产生完全相同错误。修复将系统继承条目和应用显式 set/remove 分开；后者继续严格拒绝空名称、NUL 和 `=`。实际原安装进程的环境触发项未被记录，不公开环境值或完整列表。

保持绝对 Git 可执行文件、CRT 参数引用、Unicode/ordinal 环境覆盖、受限标准句柄、挂起创建→Job→准确主线程恢复、超时/取消/子树回收的既有约束。没有清空继承环境、引入 shell 回退、改 Git 全局配置或扩展 `safe.directory`。

## 边界与验证方法

- 扫描限制候选、枚举条目、访问/排队目录、输出字节、深度与 30 秒工作预算。取消/预算仅在文件系统调用之间协作检查，阻塞中的 UNC 调用可能继续等待；真实 worker 退出前不释放其 request/singleflight 所有权。
- 原生激活代际与前端请求代际同时防止旧选择覆盖新选择，成功后原子替换 watcher；失败或取消的待激活请求保留原有效 watcher。
- 语言使用自有类型化字典和显式 TextNode/attribute 绑定，不扫描任意 DOM 或执行翻译 HTML，无新增运行时依赖。
- 保留 0.2.1 性能路径：渐进打开、patch 优先、侧内容懒加载、虚拟列表和有界缓存。历史性能记录仍仅代表原版本、原环境，不作为本轮新基准。
- 自动化覆盖环境块结构/真实子进程、扫描上限/取消/链接/无 Git 副作用、激活竞态/旧状态迁移、双语控件保留/零额外 Host 请求、状态未知/陈旧/冲突/跟踪有效性。
- 实际桌面必须用最终候选 exe、隔离 profile 和自建多仓库/worktree/bare 夹具，确认真实选择/语言/状态/布局及前后仓库完整性。真实 WSL 项目只读复验与这些夹具分开，私有路径、截图、样本与摘要不进入源码交付。
- 交付流程要求最终前端、Rust unit/integration、桌面 parity、安装升级、资源报告及同 exe 哈希；失败/Blocked 证据保留，不能用旧版本通过结果替代。
