# QGitGraph 0.2.1 性能修订交付说明

本次根据本地安装后`WSL UNC测试仓库`打开、详情/Diff等待过长的反馈，进行了真实只读分段测量、后端查询与Windows进程启动优化，以及前端加载/刷新/选择/渲染状态改造。不是仅隐藏loading或降低默认功能。

本文记录0.2.1当时的本地交付，公开版本仅匿名化私有信息；以下测量与通过数不代表0.2.2已重测或通过。

## 实测前后对比

Windows11 + Git for Windows2.47 + WebView2 157，目标位于WSL UNC。基线为只增加默认关闭计时、算法不变的0.2.0，优化版0.2.1使用相同commit/parent/file计划及Git配置。主要指标各20样本；前后HEAD、所有refs、index、status、配置与抽样工作文件一致。

| 操作 | 0.2.0 p50 | 0.2.1 p50 | 0.2.1 p95 |
|---|---:|---:|---:|
| 提交图可开始浏览 | 12.99秒 | **2.72秒** | 2.87秒 |
| 全部打开元数据完成 | 12.96秒 | **7.09秒** | 7.23秒 |
| 冷提交文件列表 | 4.30秒 | **1.13秒** | 1.52秒 |
| 冷提交首个Diff | 8.28秒 | **2.06秒** | 2.48秒 |
| 首次显式切换文件Diff | 3.96秒 | **0.95秒** | 1.00秒 |
| 缓存提交重访 | 13.4ms | 15.65ms | 35.4ms |
| 缓存文件重访 | 12.35ms | 6.35ms | 28.8ms |

选中反馈的独立绘制机会p95约17.1ms；旧版没有同一独立phase，不能填0或计算提升比例。缓存命中原本已快，微小绝对退步如实保留。显式完整刷新3样本约10.60→6.15秒，历史搜索3样本约3.96→2.09秒，仅为小样本，不能当稳定尾延迟统计。

这是单机顺序A/B，不是随机化、冷磁盘或实验室因果基准；OS/WSL缓存与宿主负载会波动。输入到双rAF是绘制机会，非物理GPU显示；Rust分段不与WebView时钟相减，不把所有嵌套span相加作总时间。完整原始方法、失败/Blocked边界及残余限制见[性能记录](performance-0.2.1.md)。

## 实际改动

- 打开/显式刷新并行加载历史与工作区状态；历史先可用，工作区未知时不冒充干净。刷新保留列表、选中、滚动，新输入/取消不被旧恢复任务覆盖。
- 历史文件先读取patch，old/new全文按需；一次冷详情+首Diff从17次Git降到7次。单文件patch从9次Git路径缩到3次，单侧内容只读请求的一侧。
- Windows后台使用documented CreateProcessW拿到的初始线程句柄，仍先挂起、Job绑定后恢复，去掉全系统线程枚举。真实Unicode/argv/8MiB输入、32MiB输出、helper子孙取消与排队取消回归通过。
- 图布局、虚拟行节点、文件树和Diff解析模型按输入复用；大文件列表虚拟化；刷新合并与dirty重放；可取消自适应搜索和有界缓存。
- 默认无性能日志、遥测、常驻服务器或额外联网；没有引入重UI框架、内嵌浏览器引擎或Git。

## 回归与运行开销

前端127、Rust单元81、真实Git/host集成85，合计**293项自动化通过**，另有16项真实桌面parity通过。实际桌面发现的审阅自动已读边界已修复并新增回归，性能数据对修复后的同一SHA重跑。默认ignored的启动计时benchmark已另行显式执行，不重复算成产品覆盖率。

最终默认诊断关闭时，全应用+WebView2 Private Bytes p50约**242.93MiB**，简单求和Working Set约456.43MiB（共享页重复计数）；4快照/72.1秒空闲，CPU实际55.3秒观测窗口约**单核0.311%**。相对0.2.0 Private约+1%，exe/安装器约+1.59%/+1.37%。输入法/系统broker和driver另列，不以Rust宿主少量内存冒充总占用。

## 仍存在的成本与环境门禁

- 该项目位于WSL UNC，Windows Git工作区遍历仍约6秒级；没有要求搬迁项目、改Git配置或暗中切换Linux Git。先可交互不等于后台全部完成。
- 单侧全文第一次按需读取会等待Git，换来普通patch首屏不读取无用全文；重复内容切换可复用缓存。二进制和超限不假装空Diff。
- 真实用户项目的GUI取消原生完成ack没有稳定证据，性能套件整体明确Blocked，不以last-wins/idle冒充清理完成；底层取消有临时fixture真实进程树回归。
- Win10/干净VM/DPI多屏/屏幕阅读器、生产认证、GPG/X.509/provider当前网页权限及Authenticode证书仍各需真实环境。当前unsigned，SmartScreen提示不被消除。
- 安装升级只针对已确认的原目录，备份完整旧安装与偏好；不使用测试卸载器删除用户安装，不强杀用户窗口，不自动回滚覆盖新状态。
