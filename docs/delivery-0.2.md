本版本沿用已确认的Windows优先、独立实现、提交图中心路线。没有直接封装或搬运原插件受限代码、样式、素材和协议；不表示上游授权、背书或像素级复刻。

## 交付位置

最终整理目录为`release/QGitGraph-0.2.0/`，保留0.1.0产物不覆盖：

- `QGitGraph-0.2.0-windows-x64/QGitGraph_0.2.0_x64-setup.exe`：当前用户NSIS安装器。
- `QGitGraph-0.2.0-windows-x64.zip`：解压运行完整目录，包含程序、安装器、文档和全部第三方许可/受覆盖源码。
- `QGitGraph-0.2.0-source.zip`：应用、测试、构建/验收脚本及锁文件；不含运行时依赖目录、构建缓存、测试配置、密钥和用户状态。
- `manifest.json`、`SHA256SUMS.txt`和`stage-result.json`：阶段完成状态、实际测试摘要、签名状态、逐项清单及最终压缩包校验值。若阶段结果缺失或不是`passed`，不能把该目录当作已完成交付。

此次仅在本地整理，没有上传、提交Git、push或公开发布。

Tauri会将NSIS应用的安装类型标记从`UNK`改为`NSS`。最终解压运行包使用实际安装后保留的同一程序，桌面、安装和资源证据绑定同一SHA，不以代码区一致为由放宽整文件校验。它可在没有安装注册的目录启动，但默认配置不是自动存exe旁；隔离配置请用`--profile-dir=ABS`。

两文件当前均未Authenticode签名。Windows可能出现SmartScreen提示；不要关闭安全检查来冒充完成签名或信誉认证。

## 功能与验收范围

多refs/glob、stash图语义、完整附注标签、包含关系、Inline详情、安全消息/gitmoji、审阅生命周期、快捷键、完整操作参数、分享配置、PR URL、显式验签、真实外部会话与状态迁移均有实现，逐项见[功能矩阵](parity-matrix.md)。

[验证记录](verification-0.2.md)区分自动化、真实桌面、系统原生和环境门禁。最终基础自动化为71项前端、53项Rust单元、60项真实Git/host集成，合计184项通过；辅助发布工具26项及安装进程竞态3项另计，不重复合并为产品覆盖率。最终程序真实桌面parity16项通过；安装目录、notice/source校验、无测试探针和完整卸载通过。

资源是系统WebView2多进程的真实开销：固定小仓库单次warm run，Private Bytes p50约240.57MiB，CPU首末快照间约单核0.305%；并非只报Rust宿主占用，也不称实验室或冷启动基准。

另用20,000真实提交、4个merge、8个refs补测首300、两次追加100及超出loaded页的message/hash搜索，结果与Git OID逐项一致，仓库与配置前后不变。单次driver+DOM首屏约5.67秒、分页约2.8秒、message搜索约2.34秒、hash搜索约14.89秒；不隐瞒慢样本，不称纯Git或百万提交性能。GUI取消因缺可靠完成确认明确optionalblocked，底层进程树取消另有真实host测试。

## 仍需真实环境的项目

- 当前验证机为Windows11；Win10、缺Git/WebView2干净VM、离线Runtime安装、实际DPI多屏/屏幕阅读器矩阵未冒充通过。
- 剪贴板回读在当前host共享OLE环境Blocked；未成功保存用户内容前不执行copy，不清空用户剪贴板。
- 真实SSO/GCM/SSH agent服务端、GPG/X.509/硬件签名及provider网页/权限需对应授权环境。临时SSH ed25519测试不代表全部PKI或生产服务认证。
- 外部editor/difftool的结构化参数及快照路径已实现；具体工具GUI需其实际环境，不能以参数构造或按钮存在代替验收。
- 复杂root/merge自动drop仍有安全保护，交互流程启动不是改写完成。资源/扫描/加载都有明确预算，超限报错而非假完整。
