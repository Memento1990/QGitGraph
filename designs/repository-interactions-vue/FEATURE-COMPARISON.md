# Vue 工作台原型功能对照与完整缺口

> 本文件保留为建立任务看板时的 **100 项来源基线快照**。后续实施、调整、证据、验收和复盘统一以 [项目任务看板](http://127.0.0.1:14732/)／`tools/taskboard/data/board.json` 为准，下面的“本轮 Vue 状态”不随每次任务更新重写。用户已要求全部适用 P0/P1 必做，验收范围调整为宽屏深浅色；旧窄屏条款不属于本轮新增工作。

## 对照口径

- **旧 v4**指 [`index-v4.html`](../repository-interactions/index-v4.html) 实际加载的独立原型，不把菜单文字、确认文案或 README 中的目标当作已经实现的行为。
- **正式应用**指本仓库 `src/ui` 等当前源码中的实际能力，不等于本机某个已安装版本。已有函数但入口被隐藏、默认值未接通、原型领先于正式应用的项目均单独说明。
- **本轮 Vue**指本目录当前源代码。下面共 **100 项**，按用户任务和操作语义拆分；GitAction 不以“分支／远程／工具”几个菜单分类代替具体子项。
- Vue 的仓库、历史、文件内容、信任规则和写操作均为**内存示例**。可验证的 mock 状态变化仍算功能，不因没有真实 Git 就全部记为缺失；真实 Git、磁盘、IPC、网络、系统窗口及外部进程属于**刻意不接真实 host**的边界。
- **源码核实不是运行验收**。各行已按处理函数／模板／数据模型核对；带 **N** 的行标记本轮导航、refs、stash、子模块或布局相关改造。明确写“浏览器验证”的结果来自本轮主任务的浏览器回归；仅核到源码而未跑相应测试的分支会明确注明，不据此宣称所有功能已验收。
- 每行最后一列按“旧／正式／Vue”给出关键证据；链接均为项目内相对链接，显示 `file:line`。同一入口复用通用说明弹窗时，证据指向实际分发函数而非仅指向 label。

| 标记 | 含义 |
